# DD-005: String Set and Tension

**Status:** Approved  
**Date:** 2026-08-11

## The Question

What standard string construction and gauges should the reference cigar box guitar use?

The string set must work with several decisions already made for the reference instrument:

- three strings;
- a 630 mm nominal scale length;
- a normal tuning envelope from G2 to G3;
- reference tunings of G2-D3-G3 and G2-B2-D3;
- a chunky, blues-focused musical character;
- both fretted and slide playing;
- amplified performance as an important part of the instrument.

The strings therefore need to provide useful tension throughout the tuning envelope without becoming objectionably loose at the bottom or excessively stiff at the top.

## Goals

The standard string set should:

- work comfortably across the normal tuning envelope defined in DD-003;
- provide a familiar to slightly firm playing feel;
- avoid excessively loose strings at the lower ends of their tuning ranges;
- avoid excessive tension at the upper ends;
- suit the chunky, blues-focused voice of the instrument;
- work naturally with a magnetic pickup;
- support both fretted and slide playing;
- allow both reference tunings without restringing;
- use readily available string gauges;
- provide a useful baseline that can be refined through experience with the completed instrument.

## String Family

The reference instrument will use nickel-wound electric-guitar strings.

Nickel-wound strings are well suited to the intended magnetic pickup and amplified character of the instrument.

Maximum unplugged acoustic projection is therefore not the primary consideration when selecting the strings.

The reference string construction will be:

- steel core;
- nickel-plated steel winding;
- round-wound construction.

Other string materials may be explored later, but the standard instrument will be designed around this family.

## Wound Strings

All three strings will be wound.

At the relatively low pitches used by the reference instrument, wound strings provide a practical way to achieve the required mass without using unusually thick plain steel strings.

Using wound strings across all three positions should also contribute to the substantial, blues-focused voice intended for the instrument.

Additional finger or slide noise from wound strings is accepted as part of the trade-off.

## Playing Feel

The desired playing feel is:

**familiar to slightly firm**

The aim is not to achieve identical tension at every tuning.

Because string tension rises substantially as a string is tuned upward, a string that covers several pitches cannot maintain the same feel throughout its range.

Instead, the design target is:

> At the lower end of each normal tuning range, the string should remain usefully playable without becoming objectionably loose. At the upper end, it should remain firm without becoming excessively stiff.

This provides a more useful design criterion than attempting to equalise tension across every possible tuning.

## Reference Gauge Set

The initial standard string set will be:

- **low string: .050 wound**
- **middle string: .032 wound**
- **high string: .025 wound**

D'Addario XL Nickel Wound strings are used as the reference construction for the initial tension calculations.

Equivalent strings from other manufacturers may behave somewhat differently because gauge alone does not completely determine string tension.

## Approximate Tension

At the 630 mm nominal scale length, the reference gauges produce approximately the following tensions:

| String | Gauge | Normal range | Approximate tension |
|---|---:|---|---:|
| Low | .050 wound | G2 | 12.0 kg |
| Middle | .032 wound | B2 to D3 | 8.4 to 11.8 kg |
| High | .025 wound | D3 to G3 | 7.4 to 13.2 kg |

These values are design estimates rather than acceptance tolerances.

Actual playing feel will be evaluated on the completed instrument.

## Reference Tuning Loads

Using the reference string set, the two reference tunings are expected to produce approximately:

### G2-B2-D3

Total string tension:

**27.7 kg**

This represents the softer end of the intended operating range.

### G2-D3-G3

Total string tension:

**37.0 kg**

This represents the firmer end of the intended operating range.

The difference in total tension between the two tunings is an expected consequence of using one string set across a flexible tuning envelope.

The instrument must therefore be designed to remain structurally stable and playable throughout this range.

## Trade-Offs

The principal trade-off is between **tuning flexibility** and **consistent string feel**.

A string set optimised for only one tuning could provide more uniform and carefully balanced tension.

The reference instrument deliberately accepts some variation in feel so that substantially different tunings can be explored without changing strings.

The chosen gauges also favour the lower-register, chunky character of the instrument rather than maximum ease of bending or a particularly light touch.

All three strings being wound may create more mechanical finger and slide noise than a set containing plain strings.

That is considered acceptable for this instrument and may contribute positively to its blues character.

## Decision

The reference cigar box guitar will use an initial standard string set of:

- **.050 wound**
- **.032 wound**
- **.025 wound**

The strings will be round-wound, nickel-plated steel electric-guitar strings.

All three strings will be wound.

The string set is intended to support the complete normal tuning envelope defined in DD-003 on the 630 mm scale established in DD-004.

The target playing feel is familiar to slightly firm, with some variation in tension accepted as a necessary consequence of tuning flexibility.

These gauges establish the reference starting configuration rather than an assumption that the first selection must remain optimal forever.

## Consequences

This decision means that:

- the nut and bridge must accommodate the selected gauges;
- tuner selection must accommodate a .050 low string;
- neck and body structures must safely withstand the highest expected normal string load;
- the magnetic pickup should be designed and positioned for nickel-wound steel strings;
- setup must remain usable across approximately 27.7 to 37.0 kg of total normal string tension;
- the instrument can move between both reference tunings without restringing;
- actual string feel will become an explicit part of the reference build evaluation;
- alternative gauges may be tested if practical experience reveals excessive looseness, stiffness or imbalance;
- any future gauge change should be evaluated against the complete tuning envelope rather than a single preferred tuning.

## Future Revisit

The reference string set should be reviewed after the completed instrument has been played extensively in both reference tunings and across the normal tuning envelope.

We should then ask:

- Does the low .050 string feel appropriate at G2?
- Does the .032 middle string remain useful from B2 through D3?
- Does the .025 high string remain comfortable from D3 through G3?
- Does the instrument feel sufficiently substantial for slide playing?
- Is the softer G2-B2-D3 configuration still controlled and responsive?
- Is the firmer G2-D3-G3 configuration comfortable for extended playing?
- Do all three wound strings contribute positively to the desired sound?
- Does the nickel-wound construction work well with the chosen pickup?
- Would different gauges provide a better balance across the tuning envelope?
- Would we choose this string set again for an instrument with similar goals?

## Sign-Off

**Approved.**

The reference cigar box guitar will begin with .050w, .032w and .025w round-wound nickel-plated steel strings, providing a practical baseline for the 630 mm scale and flexible G2-to-G3 tuning envelope.
